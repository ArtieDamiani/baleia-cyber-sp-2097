📋 ESTRATÉGIAS DETALHADAS POR PLATAFORMA
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
DEEPSEEK (Chat/Web — 1M de limite)
Configuração ideal:
├─ Pode carregar TODOS os 23 arquivos no contexto
├─ Isso consome ~270k tokens (bem abaixo do limite)
├─ Backup: a cada 100 interações
└─ Alerta: 900k (muita margem)
Vantagens: Memória GIGANTE. Pode manter o sistema inteiro.
Cuidados: Respostas podem ser mais genéricas — use prompts específicos.
DEEPSEEK (R1 — 160k)
Configuração ideal:
├─ Sempre: CAMADA 0 (48k)
├─ Sob demanda: até 112k da CAMADA 1 (escolha o que precisa)
├─ Backup: a cada 30 interações
└─ Alerta: 140k (ativar modo econômico)
Vantagens: Raciocínio profundo com R1
Cuidados: R1 consome tokens rapidamente — usar apenas para decisões importantes
CHATGPT (GPT-4o / GPT-4 Turbo — 128k)
Configuração ideal:
├─ 01_CORE como INSTRUÇÃO PERMANENTE (colar no início)
├─ Sempre: 02_PERFIL, 03_CAMPANHA
├─ ChatGPT tende a "resumir" informações antigas
├─ Reforçar checklist a cada resposta
└─ Backup: a cada 20 interações
Dica: Use "memória de conversa" para manter contexto
GEMINI (1.5/2.0 — 1M)
Configuração ideal:
├─ Pode carregar TODOS os 23 arquivos no contexto
├─ Isso consome ~270k tokens (bem abaixo do limite)
├─ Backup: a cada 100 interações
└─ Alerta: 900k (muita margem)
Vantagens: Memória GIGANTE. Pode manter o sistema inteiro.
Cuidados: Respostas podem ser mais genéricas — use prompts específicos.
📋 PROMPT DE ABERTURA RECOMENDADO PARA GEMINI:
"Você é o Triggerbot v1.0, sistema de suporte para o RPG Cyber SP 2097.
Todos os 23 arquivos do sistema estão carregados no contexto.
Siga as instruções do 01_CORE_v1.0.txt para TODAS as respostas.
Use o checklist de memória para manter consistência.
A campanha atual está em 03_CAMPANHA_X_v1.0.txt."
CLAUDE (3.5 Sonnet / 3 Opus — 200k)
Configuração ideal:
├─ Sempre: CAMADA 0 (48k)
├─ Também manter: CAMADA 1 inteira (65k) = 113k
├─ Sob demanda: partes da CAMADA 2
├─ Backup: a cada 40 interações
└─ Alerta: 180k
Vantagens: Narrativa rica, boa para descrições
Cuidados: Pode ser verborrágico — use /tema compacto
META (Llama 3) e OUTROS (8k a 128k)
Configuração ideal:
├─ Apenas 01_CORE + 03_CAMPANHA
├─ 02_PERFIL condensado (se possível)
├─ Backups MUITO frequentes (a cada 10-15 interações)
└─ Usar /migrar para gerar resumo executivo
Cuidado redobrado: Testar limites antes de campanhas longas
